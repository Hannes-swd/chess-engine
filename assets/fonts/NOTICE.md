# Material Icons

`MaterialIcons-Regular.ttf` und `MaterialIcons-Regular.codepoints` stammen aus
[google/material-design-icons](https://github.com/google/material-design-icons) (Ordner `font/`).

Copyright Google LLC. Lizenziert unter der Apache License, Version 2.0:
<https://www.apache.org/licenses/LICENSE-2.0>

Die Icons werden unverändert verwendet. Welches Icon welches Zeichen ist, steht in der
`.codepoints`-Datei; im Code sind die benutzten Icons in `src/ui/icons.hpp` hinterlegt.
